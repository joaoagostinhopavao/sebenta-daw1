1.1 Perfis de Programador Web

O desenvolvimento web organiza-se, tradicionalmente, em três perfis, que se distinguem pelo lado da aplicação em que trabalham.

1.1.1 Frontend

O programador de frontend trabalha do lado do cliente, isto é, no browser, e é responsável pela interface com que o utilizador interage diretamente. As ferramentas de base são o HTML, a CSS e o JavaScript, frequentemente com o apoio de frameworks como o React, o Vue.js ou o Angular. O React é hoje o mais usado, mas o Vue.js consolidou-se como segunda opção mais adotada globalmente, à frente do Angular em satisfação dos programadores («State of JavaScript 2025: Front-end Frameworks» 2025).

1.1.2 Backend

O programador de backend trabalha do lado do servidor: implementa a lógica de negócio, gere o acesso a bases de dados e expõe essa lógica ao exterior, tipicamente através da API do protocolo HTTP. Usa linguagens como o PHP, o Python ou o JavaScript (em ambiente Node.js), e sistemas de gestão de bases de dados como o MySQL, o MariaDB, o PostgreSQL ou o MongoDB. Ocupa-se ainda de tarefas de configuração de servidores e de implantação (deployment) da aplicação.

1.1.3 Full Stack

O programador full stack trabalha nos dois lados, frontend e backend, com as ferramentas acima descritas ou com frameworks que integram as duas componentes, como o Laravel (em PHP), o Django ou o FastAPI (em Python), ou o Next.js (em JavaScript/TypeScript).

1.2 Ferramentas de Trabalho

Independentemente do perfil, um programador web trabalha tipicamente com o seguinte conjunto de ferramentas:

  • Computador e sistema operativo: macOS, Windows ou Linux;
  • Browser: Chrome, Firefox, Safari ou Edge, para testar o resultado do trabalho;
  • Editor de texto ou IDE: Visual Studio Code, Sublime Text ou uma IDE mais completa, como o WebStorm;
  • Terminal: a linha de comandos do macOS ou Linux, ou o PowerShell ou Git Bash no Windows;
  • Software de design: para protótipos e interfaces, sendo o Figma a ferramenta de referência do mercado (Mapsoft, s.d.).

1.3 HTML e CSS: os Blocos Básicos

O HTML e a CSS são os blocos de construção fundamentais de qualquer página web: o HTML estrutura o conteúdo e a CSS define a sua apresentação visual. Um programador de frontend deve dominar, no mínimo:

  • As tags básicas e semânticas do HTML5;
  • Os fundamentos da CSS: seletores, propriedades e o modelo de caixa;
  • Alinhamentos e grelhas em CSS, com recurso a Flexbox e CSS Grid;
  • Media queries e desenho responsivo, para que a página funcione em diferentes tamanhos de ecrã;
  • Animações e transições simples.

1.4 Frameworks e Pré-processadores CSS

Escrever CSS pura para um projeto grande é possível, mas trabalhoso. Surgiram por isso frameworks CSS, bibliotecas de estilos e componentes prontos a usar. O Tailwind CSS é hoje o mais usado, à frente do Bootstrap («Top CSS Frameworks in 2025: What Devs Actually Use» 2025); o Foundation mantém-se como opção de nicho, sobretudo em projetos empresariais já existentes.

Para além de frameworks de componentes, existem ferramentas que estendem a própria linguagem CSS. O Sass é um pré-processador que acrescenta funcionalidades à CSS, como variáveis, aninhamento de seletores e mixins; o PostCSS transforma CSS através de plugins em JavaScript, com funcionalidades semelhantes. O aninhamento nativo de seletores, as variáveis nativas (custom properties) e funcionalidades como o color-mix() já fazem parte da própria linguagem CSS, com suporte alargado nos browsers modernos («Native CSS Nesting: Sass Syntax With No Build Step (And One Big Trap)» 2025), cobrindo grande parte do que motivava o uso de um pré-processador.

1.5 O Que um Frontend Iniciado Deve Saber

Resumindo o que se espera de um programador de frontend em início de carreira:

  • Criar layouts web com HTML e CSS;
  • Saber JavaScript e trabalhar com o DOM (Document Object Model);
  • Criar pequenas aplicações de frontend interativas;
  • Ser capaz de ligar essas aplicações a APIs externas;
  • Trabalhar com o Git e usar controlo de versões;
  • Instalar e gerir pequenos projetos reais, já em produção.

1.6 Tecnologias do Lado do Servidor

As tecnologias do lado do servidor organizam-se em três grandes grupos: linguagens e frameworks, bases de dados, e a programação através da API do protocolo HTTP.

1.6.1 Linguagens

Do lado do servidor, o panorama de linguagens inclui, entre outras, Node.js (JavaScript no servidor), Python, PHP, C#, Go, Ruby, Java, Kotlin, Rust, Scala e Swift. O PHP é uma das linguagens mais usadas do lado do servidor, sobretudo pela sua ligação histórica ao WordPress e a grande parte da Web publicada em sistemas de gestão de conteúdos.

1.6.2 Frameworks de Servidor

Cada linguagem de backend tem os seus próprios frameworks de desenvolvimento web. Em JavaScript, destacam-se o Express, o Koa, o Fastify e o Next.js; em Python, o Django, o Flask e o FastAPI; em PHP, o Laravel, o Symfony e o Slim. O Laravel é hoje o framework PHP mais usado, à frente do Symfony (JetBrains 2025).

1.6.3 Bases de Dados e ORMs

As bases de dados dividem-se, essencialmente, em dois grandes grupos:

  • Relacionais, organizadas em tabelas com esquema fixo e relações entre elas, como o PostgreSQL, o MySQL ou o SQLite;
  • Não relacionais (NoSQL), com esquemas mais flexíveis, como o MongoDB e o Firebase (Cloud Firestore), ambos orientados a documentos (Google, s.d.), ou o Redis (chave-valor, muito usado para cache).

Para facilitar o acesso a bases de dados a partir de código orientado a objetos, usam-se com frequência ferramentas de mapeamento objeto-relacional (ORM), como o Eloquent (o ORM nativo do Laravel), o Prisma, o Drizzle ou o TypeORM em JavaScript/TypeScript, o Mongoose para MongoDB, ou o SQLAlchemy em Python. O Prisma é o mais usado em número de projetos, mas o Drizzle tem crescido com destaque entre projetos que privilegiam um controlo mais direto sobre o SQL gerado (Bytebase 2026).
