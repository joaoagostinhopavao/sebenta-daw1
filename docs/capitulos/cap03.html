3.1 Preparar o Ambiente de Desenvolvimento

Antes de escrever a primeira linha de código PHP, é necessário preparar um ambiente onde esse código possa ser executado: um servidor web capaz de interpretar PHP, ligado a um sistema de gestão de bases de dados. Como visto no Secção 2.2.3, há duas abordagens principais para isolar este ambiente do sistema operativo do computador de cada aluno, evitando que o resultado de um trabalho dependa de particularidades desse computador: máquinas virtuais e contentores. Esta secção descreve, de forma resumida, como cada uma destas abordagens se aplica especificamente ao desenvolvimento em PHP; os passos completos de instalação e configuração, com todos os comandos necessários, ficam reservados para o Secção A.1, já que são detalhes de configuração, não de programação, e podem variar consoante o sistema operativo do computador de cada aluno e a versão exata de cada ferramenta. Note-se ainda que o professor das aulas práticas pode implementar este ambiente com especificações mais concretas do que as aqui descritas; o objetivo desta secção é apenas garantir que o ambiente de programação em PHP fica claro em termos gerais, independentemente desses detalhes finais.

Na prática, não é necessário que cada aluno construa este ambiente do zero: o professor da componente prática disponibiliza normalmente uma imagem já preparada, seja de uma máquina virtual completa, seja de um ou mais contentores Docker (por exemplo, um contentor para o Apache e o PHP, e outro separado para o MySQL), prontos a importar e a usar. As duas opções descritas de seguida, com os passos completos no Secção A.1, destinam-se sobretudo a quem prefere montar o próprio ambiente, por exemplo num computador pessoal fora do contexto da aula, ou a quem simplesmente quer compreender, em detalhe, do que é feito o ambiente que lhe é disponibilizado.

3.1.1 Opção 1: Máquina Virtual

É a abordagem seguida por omissão nesta UC, já apresentada no Secção 2.2.4: uma máquina virtual VirtualBox com Ubuntu, onde se instalam o servidor Apache, o MySQL e o PHP, individualmente ou através de um pacote pré-configurado, consoante o sistema operativo do computador de cada aluno. Todo o desenvolvimento, desde a edição do código até ao teste no browser, acontece dentro desta máquina virtual, que se comporta, para efeitos práticos, como um pequeno servidor próprio e isolado do resto do computador.

3.1.2 Opção 2: Contentores (Docker)

Uma alternativa é usar o Docker, referido no Secção 2.2.3, para correr o Apache, o PHP e o MySQL cada um no seu próprio contentor, em vez de os instalar dentro de uma máquina virtual completa. É uma opção mais leve, com arranque mais rápido, especialmente adequada a quem já tem alguma experiência com Docker, ou a um computador com menos recursos disponíveis para correr uma máquina virtual inteira.

3.1.3 O Que Se Pretende Obter

Seja qual for a opção escolhida, o resultado final é o mesmo, e é isso que importa reter para o resto deste capítulo:

  • Um servidor Apache a correr, capaz de interpretar código PHP;
  • Um servidor MySQL a correr, acessível a partir do código PHP;
  • Um editor de código, tipicamente o Visual Studio Code, com acesso direto aos ficheiros do projeto;
  • A possibilidade de abrir um ficheiro .php num browser, através de um endereço como http://localhost, e ver o resultado da sua execução.

Com este ambiente preparado, seja através da imagem fornecida pelo professor, seja seguindo os passos detalhados no Secção A.1, está reunido tudo o que é necessário para começar, finalmente, a escrever e a testar código PHP.

3.2 A Linguagem PHP

PHP (Hypertext Preprocessor) é uma linguagem de script que corre do lado do servidor. Ao contrário do HTML e do JavaScript, que o browser recebe e interpreta diretamente, o código PHP é executado no servidor, e o cliente recebe apenas o resultado desse processamento, tipicamente HTML. Isto significa que o código PHP nunca é visível a quem visita o sítio, mesmo que este veja o código-fonte da página no browser: tudo o que o cliente recebe já é o resultado da execução do PHP, nunca o código PHP em si.

Uma secção de código PHP começa sempre com <?php e pode ser fechada com ?>, embora, em ficheiros que só contenham PHP, seja habitual omitir a marca de fecho, para evitar espaços em branco acidentais depois dela. O PHP pode ser inserido no meio de HTML, misturando as duas linguagens no mesmo ficheiro, entrando e saindo do modo PHP quantas vezes for necessário:

<!DOCTYPE html>
<html>
<body>
  <h1>Olá!</h1>
  <?php
    echo "<p>São agora " . date("H:i") . "</p>";
  ?>
  <p>Este texto já não é PHP, é HTML normal.</p>
  <?php
    $visitas = 128;
    echo "<p>Este sítio já foi visitado $visitas vezes.</p>";
  ?>
</body>
</html>

3.3 Sintaxe Básica

Todos os comandos PHP terminam com ponto e vírgula (;); esquecê-lo é um dos erros mais comuns de quem começa a programar em PHP, e produz tipicamente um erro de sintaxe (parse error) que impede a página de carregar. Os comentários de uma linha fazem-se com //, e os de várias linhas com /* ... */:

<?php
// Este comentário de uma linha não aparece na página

/* Este comentário
   pode ocupar
   várias linhas */

echo "Olá, Mundo!";

Para mostrar um valor, usa-se o comando echo, que pode receber vários valores separados por vírgula:

<?php
echo "Olá, Mundo!";
echo "Nome: ", "João", ", Idade: ", 25;

3.4 Variáveis

Uma variável é um “contentor” para armazenar dados que o programa vai usar. Em PHP, o nome de uma variável tem de obedecer a um conjunto de regras precisas:

  • Começa sempre pelo símbolo $;
  • Depois do $, o nome tem de começar por uma letra ou por um underscore (_), nunca por um número;
  • Só pode conter letras, números e underscores, sem espaços nem outros símbolos;
  • É sensível a maiúsculas e minúsculas (case sensitive): $idade e $Idade são duas variáveis diferentes, um erro comum que pode gerar bastante confusão ao depurar um script.
<?php
$idade = 19;       // válido
$_total = 0;       // válido, começa por underscore
$nome_completo = "Ana Silva";  // válido

$1idade = 19;      // INVÁLIDO: não pode começar por número

3.5 Tipos de Dados

Ao contrário de linguagens como o Java ou o C#, o PHP não obriga a declarar o tipo de uma variável: o tipo é determinado automaticamente pelo valor atribuído, e pode mudar se a variável receber um valor de outro tipo mais tarde. A esta característica chama-se tipagem dinâmica. O PHP suporta os seguintes tipos de dados:

  • String: texto, delimitado por aspas simples ou duplas;
  • Integer: números inteiros, positivos ou negativos, sem casas decimais;
  • Float (ou double): números com casas decimais;
  • Boolean: os valores true ou false;
  • Array: uma coleção de vários valores, tema detalhado na secção seguinte;
  • Object: uma instância de uma classe, agrupando dados e comportamento;
  • NULL: um tipo especial, com um único valor possível, null, que representa a ausência de valor;
  • Resource: uma referência a um recurso externo ao PHP, como uma ligação aberta a uma base de dados ou a um ficheiro.

Os quatro primeiros, string, integer, float e boolean, são os tipos simples usados no dia a dia da programação; os restantes, array, object, NULL e resource, aparecem ao longo desta UC à medida que os programas se tornam mais complexos.

<?php
$idade = 19;                  // integer
$preco_do_almoco = 10.5;      // float
$texto = "Olá, Mundo!";       // string
$porta_aberta = true;         // boolean
$sem_valor = null;            // NULL

A função gettype() devolve o tipo atual de uma variável, o que é particularmente útil enquanto se aprende a linguagem, já que os erros de tipo em PHP nem sempre são óbvios:

<?php
echo gettype($idade);           // integer
echo gettype($preco_do_almoco); // double
echo gettype($porta_aberta);    // boolean

Um exemplo típico de confusão para quem começa: echo de um valor booleano mostra 1 para true, mas não mostra literalmente nada para false, o que pode parecer, à primeira vista, um erro do próprio programa, quando é apenas o comportamento normal do PHP.

Strings podem ser concatenadas com o operador ., e é possível misturar texto e variáveis diretamente numa mesma instrução echo, seja por concatenação, seja escrevendo a variável dentro de uma string entre aspas duplas:

<?php
$nome = "Ana";
$idade = 25;

echo "Nome: " . $nome . ", Idade: " . $idade . " anos";  // por concatenação
echo "Nome: $nome, Idade: $idade anos";                  // dentro de aspas duplas

Note-se que esta interpolação de variáveis só funciona com aspas duplas; dentro de aspas simples, $nome seria mostrado literalmente, sem ser substituído pelo seu valor.

3.5.1 Conversão de Tipos

Apesar de a tipagem em PHP ser dinâmica, é frequentemente necessário converter explicitamente um valor de um tipo para outro, por exemplo para garantir que um número recebido de um formulário HTML, que chega sempre como string, é tratado como número antes de ser usado num cálculo. Esta conversão faz-se colocando o tipo pretendido, entre parênteses, antes do valor:

<?php
$idade_texto = "25";           // string, como chegaria de um formulário
$idade = (int) $idade_texto;   // 25, agora um integer

$preco = "10.5";
$preco_num = (float) $preco;   // 10.5, agora um float

$numero = 0;
$estado = (bool) $numero;      // false: 0, "", "0" e null convertem-se a false

echo gettype($idade);   // integer
echo gettype($estado);  // boolean

O PHP também converte tipos automaticamente, sem ser preciso pedir, sempre que uma operação o exige: numa soma, uma string puramente numérica é convertida para número sem qualquer aviso:

<?php
$a = "10";
$b = "5";

echo $a + $b;   // 15 (inteiro), as strings são convertidas automaticamente
echo $a . $b;   // "105" (string), o operador . força a concatenação

Este comportamento é útil, mas também uma fonte comum de confusão para quem começa: o mesmo símbolo + soma números, mas o . concatena texto, e é fácil trocar um pelo outro sem que o PHP assinale qualquer erro, apenas produzindo um resultado inesperado.

3.6 Arrays

Um array é uma estrutura de dados que permite armazenar múltiplos valores relacionados numa única variável, acessíveis através de índices numéricos ou de chaves associativas, em vez de se criar uma variável separada para cada valor. O PHP disponibiliza três tipos de arrays.

3.6.1 Arrays Indexados

Num array indexado (ou numérico), cada valor é acedido através de um índice inteiro, que começa sempre em 0:

<?php
$frutas = array("Maçã", "Banana", "Laranja");

echo $frutas[0];  // Maçã
echo $frutas[1];  // Banana
echo $frutas[2];  // Laranja

$frutas[] = "Kiwi";       // acrescenta um novo elemento ao fim
echo count($frutas);      // 4, o número de elementos do array

A partir do PHP 5.4, array("Maçã", "Banana") pode também ser escrito com a sintaxe abreviada ["Maçã", "Banana"], hoje a forma mais comum de o encontrar em código PHP recente.

Para além de count(), o PHP disponibiliza várias funções para trabalhar com o conteúdo de um array indexado, sem ter de percorrer os seus elementos manualmente:

<?php
$notas = [14, 18, 9, 16];

array_push($notas, 12);        // acrescenta 12 ao fim, tal como $notas[] = 12
$ultima = array_pop($notas);   // remove e devolve o último elemento (12)

sort($notas);                  // ordena por ordem crescente, reindexando o array
print_r($notas);               // [9, 14, 16, 18]

if (in_array(16, $notas)) {
    echo "Encontrada uma nota de 16 valores";
}

$posicao = array_search(14, $notas);   // devolve o índice onde está o 14
echo $posicao;

3.6.2 Arrays Associativos

Num array associativo, cada valor é acedido através de uma chave à escolha, tipicamente uma string, em vez de um índice numérico, o que torna o código mais legível quando cada valor tem um significado próprio:

<?php
$pessoa = array(
    "nome"   => "João",
    "idade"  => 25,
    "cidade" => "Lisboa"
);

echo $pessoa["nome"];    // João
echo $pessoa["idade"];   // 25

$pessoa["profissao"] = "Programador";  // acrescenta uma nova chave

3.6.3 Arrays Multidimensionais

Um array multidimensional é um array cujos valores são, eles próprios, outros arrays, o que permite representar dados mais estruturados, como categorias com listas de itens, ou uma lista de registos, cada um com vários campos:

<?php
$carros = array(
    "desportivos" => array("Ferrari", "Lamborghini", "Porsche"),
    "suv"         => array("BMW X5", "Audi Q7", "Mercedes GLE")
);

echo $carros["desportivos"][0];  // Ferrari
echo $carros["suv"][1];          // Audi Q7

// Um array de registos, cada um por sua vez um array associativo
$alunos = array(
    array("nome" => "Ana",  "nota" => 16),
    array("nome" => "Rui",  "nota" => 14),
    array("nome" => "Sara", "nota" => 18)
);

echo $alunos[0]["nome"];  // Ana
echo $alunos[2]["nota"];  // 18

Este último exemplo, um array de arrays associativos, é a forma mais comum de representar, em memória, um conjunto de registos vindos de uma base de dados, tema retomado com mais detalhe no Secção 8.1.

Para inspecionar rapidamente o conteúdo de um array durante o desenvolvimento, sem ter de aceder a cada elemento individualmente, usa-se a função print_r(), que mostra a sua estrutura completa, incluindo arrays aninhados, ou var_dump(), que mostra ainda o tipo e o comprimento de cada valor.

3.6.4 Exemplo Completo: Média de um Aluno

Um pequeno exemplo, juntando variáveis, tipos, conversão e arrays multidimensionais, mostra bem como estes conceitos se combinam na prática: calcular a média de um aluno a partir de um array de notas, guardado dentro de um array associativo com os seus dados:

<?php
$aluno = [
    "nome"  => "Marta",
    "notas" => [15, 12, 18, 14]
];

$soma = array_sum($aluno["notas"]);           // 59
$numero_notas = count($aluno["notas"]);       // 4
$media = $soma / $numero_notas;               // 14.75

echo $aluno["nome"] . " tem média de " . $media;

if ($media >= 10) {
    echo ", está aprovado.";
} else {
    echo ", está reprovado.";
}

Note-se que array_sum() devolve um float sempre que a divisão não é exata, mesmo que todas as notas somadas sejam inteiros, o que é consistente com o comportamento de tipagem dinâmica visto na Secção 3.5: o PHP escolhe automaticamente o tipo mais adequado ao resultado de cada operação.
