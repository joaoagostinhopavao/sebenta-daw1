3.1 Preparar o Ambiente de Desenvolvimento

Antes de escrever a primeira linha de código PHP, é necessário um ambiente onde esse código possa ser executado: um servidor Apache capaz de interpretar PHP, ligado a um MySQL, tal como visto no Secção 2.2.4. Na prática, não é necessário que cada aluno construa este ambiente do zero: o professor da componente prática disponibiliza normalmente uma imagem já preparada, seja de uma máquina virtual, seja de contentores Docker, prontos a importar e a usar. Os passos completos de preparação deste ambiente, por qualquer uma das duas vias, ficam reservados para o Secção A.1, já que são detalhes de configuração, não de programação, e podem variar consoante o sistema operativo do computador de cada aluno.

O que importa reter, para o resto deste capítulo, é apenas o resultado: um Apache a correr, capaz de interpretar PHP, ligado a um MySQL, um editor de código como o Visual Studio Code com acesso aos ficheiros do projeto, e a possibilidade de abrir um ficheiro .php num browser e ver o resultado da sua execução. Com este ambiente preparado, está reunido tudo o que é necessário para começar, finalmente, a escrever e a testar código PHP.

3.2 O Projeto: Revista Contraponto

Ao longo deste e dos próximos capítulos, os exemplos de código acompanham um mesmo projeto, para que cada conceito novo se veja aplicado a um problema real, em vez de exemplos soltos e sem ligação entre si.

Rita Ferreira dirige há mais de dez anos a Contraponto, uma revista cultural em papel, e quer agora uma versão digital: um sítio onde os artigos da revista fiquem disponíveis online, organizados por categoria, com espaço para os leitores comentarem. Tiago Correia, finalista de Comunicação e Multimédia, aceita o desafio de construir esse sítio ao longo do semestre, aplicando o que vai aprendendo nesta UC.

Antes de escrever a primeira linha de código, Tiago propõe a Rita um esboço simples dos dados que o sítio vai precisar de guardar:

  • Artigo: cada peça de conteúdo publicada (título, resumo, texto, autor, categoria, data de publicação);
  • Autor: quem escreve os artigos da revista;
  • Categoria: o tema de cada artigo, por exemplo Cultura, Tecnologia ou Música;
  • Comentário: o que os leitores escrevem sobre um artigo.

Este esboço não é ainda uma base de dados, apenas um mapa do problema: a implementação, capítulo a capítulo, começa pelas partes mais simples, e só junta complexidade nova à medida que Tiago aprende novas ferramentas da linguagem, dos arrays vistos no Secção 3.8 às tabelas de uma base de dados a partir do Secção 8.1.

3.3 Arquitetura e Atribuição de Responsabilidades

Antes de decidir com que linguagem programar o sítio da Contraponto, importa perceber onde é que cada peça do problema se encaixa. A arquitetura em três camadas, já apresentada no Secção 2.1.3, distribui uma aplicação como esta em três partes: apresentação, lógica e dados. A figura seguinte aplica esta distribuição ao projeto esboçado no Secção 3.2:

A camada de apresentação é o que Tiago já domina desde o primeiro ano do curso: o HTML estrutura cada página do sítio, a lista de artigos, a página de um artigo, o formulário de comentário, a CSS trata da sua apresentação visual, e o JavaScript pode, mais tarde, tornar a interface mais dinâmica. Nada disto muda nesta UC; é o ponto de partida sobre o qual todo o trabalho seguinte se constrói.

O que falta a Tiago é a camada de lógica: o código que corre no servidor, decide que artigos mostrar, e valida o comentário submetido por um leitor antes de o passar à camada de dados. Como visto no Secção 1.6.1, esta camada pode ser escrita em qualquer uma de várias linguagens de servidor, Node.js, Python ou PHP, entre outras; esta UC escolhe o PHP, uma das mais usadas neste papel. A camada de dados, a que a lógica recorre para consultar ou guardar artigos, autores, categorias e comentários, só é introduzida a partir do Secção 8.1; até lá, é a própria camada de lógica que guarda estes dados, em memória, tal como se vê já na secção seguinte. É a partir daqui que o resto deste capítulo, e de todos os seguintes, se dedica a construir a camada de lógica da Contraponto.

3.4 A Linguagem PHP

PHP (Hypertext Preprocessor) é uma linguagem de script que corre do lado do servidor. Ao contrário do HTML e do JavaScript, que o browser recebe e interpreta diretamente, o código PHP é executado no servidor, e o cliente recebe apenas o resultado desse processamento, tipicamente HTML. Isto significa que o código PHP nunca é visível a quem visita o sítio, mesmo que este veja o código-fonte da página no browser: tudo o que o cliente recebe já é o resultado da execução do PHP, nunca o código PHP em si.

Uma secção de código PHP começa sempre com <?php e pode ser fechada com ?>, embora, em ficheiros que só contenham PHP, seja habitual omitir a marca de fecho, para evitar espaços em branco acidentais depois dela. O PHP pode ser inserido no meio de HTML, misturando as duas linguagens no mesmo ficheiro, entrando e saindo do modo PHP quantas vezes for necessário:

<!DOCTYPE html>
<html>
<body>
  <h1>Olá!</h1>
  <?php
    echo "<p>São agora " . date("H:i") . "</p>";
  ?>
  <p>Este texto já não é PHP, é HTML normal.</p>
  <?php
    $visitas = 128;
    echo "<p>Este sítio já foi visitado $visitas vezes.</p>";
  ?>
</body>
</html>

O PHP suporta dois estilos de programação: o procedimental, uma sequência de instruções e chamadas a funções, que é o que este livro segue como base, e o orientado a objetos, em que dados e comportamento se agrupam em objetos, criados com new e manipulados através de métodos, chamados com uma seta (->). O PHP recorre a objetos nalgumas das suas próprias ferramentas internas, como a classe DateTime, vista no Secção 5.2; nesses casos, introduz-se apenas a sintaxe necessária para os usar, sem que seja preciso, para já, saber construir os próprios objetos.

3.5 Sintaxe Básica

Todos os comandos PHP terminam com ponto e vírgula (;); esquecê-lo é um dos erros mais comuns de quem começa a programar em PHP, e produz tipicamente um erro de sintaxe (parse error) que impede a página de carregar. Os comentários de uma linha fazem-se com //, e os de várias linhas com /* ... */:

<?php
// Este comentário de uma linha não aparece na página

/* Este comentário
   pode ocupar
   várias linhas */

echo "Olá, Mundo!";

Para mostrar um valor, usa-se o comando echo, que pode receber vários valores separados por vírgula:

<?php
echo "Olá, Mundo!";
echo "Nome: ", "João", ", Idade: ", 25;

3.6 Variáveis

Uma variável é um “contentor” para armazenar dados que o programa vai usar. Em PHP, o nome de uma variável tem de obedecer a um conjunto de regras precisas:

  • Começa sempre pelo símbolo $;
  • Depois do $, o nome tem de começar por uma letra ou por um underscore (_), nunca por um número;
  • Só pode conter letras, números e underscores, sem espaços nem outros símbolos;
  • É sensível a maiúsculas e minúsculas (case sensitive): $idade e $Idade são duas variáveis diferentes, um erro comum que pode gerar bastante confusão ao depurar um script.
<?php
$idade = 19;       // válido
$_total = 0;       // válido, começa por underscore
$nome_completo = "Ana Silva";  // válido

$1idade = 19;      // INVÁLIDO: não pode começar por número

3.7 Tipos de Dados

Ao contrário de linguagens como o Java ou o C#, o PHP não obriga a declarar o tipo de uma variável: o tipo é determinado automaticamente pelo valor atribuído, e pode mudar se a variável receber um valor de outro tipo mais tarde. A esta característica chama-se tipagem dinâmica. O PHP suporta os seguintes tipos de dados:

  • String: texto, delimitado por aspas simples ou duplas;
  • Integer: números inteiros, positivos ou negativos, sem casas decimais;
  • Float (ou double): números com casas decimais;
  • Boolean: os valores true ou false;
  • Array: uma coleção de vários valores, tema detalhado na secção seguinte;
  • Object: uma instância de uma classe, agrupando dados e comportamento;
  • NULL: um tipo especial, com um único valor possível, null, que representa a ausência de valor;
  • Resource: uma referência a um recurso externo ao PHP, como uma ligação aberta a uma base de dados ou a um ficheiro.

Os quatro primeiros, string, integer, float e boolean, são os tipos simples usados no dia a dia da programação; os restantes, array, object, NULL e resource, aparecem ao longo desta UC à medida que os programas se tornam mais complexos.

<?php
$idade = 19;                  // integer
$preco_do_almoco = 10.5;      // float
$texto = "Olá, Mundo!";       // string
$porta_aberta = true;         // boolean
$sem_valor = null;            // NULL

A função gettype() devolve o tipo atual de uma variável, o que é particularmente útil enquanto se aprende a linguagem, já que os erros de tipo em PHP nem sempre são óbvios:

<?php
echo gettype($idade);           // integer
echo gettype($preco_do_almoco); // double
echo gettype($porta_aberta);    // boolean

Um exemplo típico de confusão para quem começa: echo de um valor booleano mostra 1 para true, mas não mostra literalmente nada para false, o que pode parecer, à primeira vista, um erro do próprio programa, quando é apenas o comportamento normal do PHP.

Strings podem ser concatenadas com o operador ., e é possível misturar texto e variáveis diretamente numa mesma instrução echo, seja por concatenação, seja escrevendo a variável dentro de uma string entre aspas duplas:

<?php
$nome = "Ana";
$idade = 25;

echo "Nome: " . $nome . ", Idade: " . $idade . " anos";  // por concatenação
echo "Nome: $nome, Idade: $idade anos";                  // dentro de aspas duplas

Note-se que esta interpolação de variáveis só funciona com aspas duplas; dentro de aspas simples, $nome seria mostrado literalmente, sem ser substituído pelo seu valor.

3.7.1 Conversão de Tipos

Apesar de a tipagem em PHP ser dinâmica, é frequentemente necessário converter explicitamente um valor de um tipo para outro, por exemplo para garantir que um número recebido de um formulário HTML, que chega sempre como string, é tratado como número antes de ser usado num cálculo. Esta conversão faz-se colocando o tipo pretendido, entre parênteses, antes do valor:

<?php
$idade_texto = "25";           // string, como chegaria de um formulário
$idade = (int) $idade_texto;   // 25, agora um integer

$preco = "10.5";
$preco_num = (float) $preco;   // 10.5, agora um float

$numero = 0;
$estado = (bool) $numero;      // false: 0, "", "0" e null convertem-se a false

echo gettype($idade);   // integer
echo gettype($estado);  // boolean

O PHP também converte tipos automaticamente, sem ser preciso pedir, sempre que uma operação o exige: numa soma, uma string puramente numérica é convertida para número sem qualquer aviso:

<?php
$a = "10";
$b = "5";

echo $a + $b;   // 15 (inteiro), as strings são convertidas automaticamente
echo $a . $b;   // "105" (string), o operador . força a concatenação

Este comportamento é útil, mas também uma fonte comum de confusão para quem começa: o mesmo símbolo + soma números, mas o . concatena texto, e é fácil trocar um pelo outro sem que o PHP assinale qualquer erro, apenas produzindo um resultado inesperado.

3.8 Arrays

Tiago começa pela parte mais visível do sítio da Contraponto: a lista de artigos publicados. Uma primeira tentativa, talvez a mais óbvia para quem começa a programar, seria criar uma variável para cada título:

<?php
$artigo1 = "Entrevista: o futuro do jornalismo local";
$artigo2 = "Crítica: a nova exposição do museu";
$artigo3 = "Como nasceu a Contraponto";

Esta abordagem funciona enquanto a revista tiver três artigos, mas torna-se rapidamente insustentável: e se a revista publicar cinquenta artigos? E se um artigo for retirado do ar, ou for publicado um novo? Seria necessário criar, apagar ou renomear variáveis uma a uma, e qualquer código que precisasse de percorrer “todos os artigos” teria de ser reescrito cada vez que o número de artigos mudasse. Faltam ainda, a esta abordagem, respostas simples a perguntas do dia a dia de um sítio deste tipo: quantos artigos estão publicados? Qual a lista de títulos, por ordem alfabética? Nenhuma destas perguntas tem resposta fácil com variáveis separadas.

A solução é um array: uma estrutura de dados que permite armazenar múltiplos valores relacionados numa única variável, acessíveis através de índices numéricos ou de chaves associativas, em vez de se criar uma variável separada para cada valor. O PHP disponibiliza três tipos de arrays, cada um mais adequado a um tipo diferente de problema, como as próximas secções mostram, retomando sempre o sítio da Contraponto.

3.8.1 Arrays Indexados

O tipo mais simples de array é o array indexado (ou numérico), em que cada valor é acedido através de um índice inteiro, que começa sempre em 0. É a estrutura certa para o problema dos títulos da Contraponto, já que não há necessidade de dar um nome próprio a cada artigo, apenas de os guardar todos juntos:

<?php
$titulos = array(
    "Entrevista: o futuro do jornalismo local",
    "Crítica: a nova exposição do museu",
    "Como nasceu a Contraponto"
);

echo $titulos[0];  // Entrevista: o futuro do jornalismo local
echo $titulos[1];  // Crítica: a nova exposição do museu
echo $titulos[2];  // Como nasceu a Contraponto

$titulos[] = "Roteiro cultural de outubro";  // acrescenta um novo elemento ao fim
echo count($titulos);                        // 4, o número de elementos do array

Duas das perguntas de Tiago ficam já resolvidas com muito pouco código: publicar um novo artigo é uma única instrução, $titulos[] = "Roteiro cultural de outubro", sem necessidade de declarar mais nenhuma variável; e saber quantos artigos estão publicados é apenas count($titulos), o número de elementos do array, que se mantém sempre correto por muitos artigos que sejam publicados ou retirados.

A partir do PHP 5.4, array("...", "...") pode também ser escrito com a sintaxe abreviada ["...", "..."], hoje a forma mais comum de o encontrar em código PHP recente.

Falta ainda responder à terceira pergunta de Tiago: qual a lista de artigos, por ordem alfabética? Para além de count(), o PHP disponibiliza várias outras funções para trabalhar com o conteúdo de um array indexado, sem ter de percorrer os seus elementos manualmente:

<?php
$categorias = ["Tecnologia", "Cultura", "Música", "Cinema"];

array_push($categorias, "Entrevistas");   // acrescenta ao fim
$ultima = array_pop($categorias);         // remove o último elemento

sort($categorias);                        // ordena por ordem alfabética
print_r($categorias);                     // [Cinema, Cultura, Música, Tecnologia]

if (in_array("Música", $categorias)) {
    echo "A categoria Música já existe";
}

$posicao = array_search("Cultura", $categorias);   // índice de "Cultura"
echo $posicao;

Aplicada ao problema inicial, sort($titulos) reordenaria os títulos dos artigos por ordem alfabética, tal como este exemplo ordena as categorias, já que o PHP usa o mesmo mecanismo de comparação para texto e para números, apenas com critérios de ordenação diferentes consoante o tipo de valor. As restantes funções também respondem a necessidades comuns de gestão de uma lista: in_array() verifica se uma categoria já existe antes de a acrescentar de novo, e array_search() devolve a posição de uma categoria específica, útil, por exemplo, para a remover mais tarde.

3.8.2 Arrays Associativos

Um array indexado resolve bem uma simples lista de títulos, mas o sítio da Contraponto vai rapidamente precisar de guardar mais informação sobre cada artigo, não apenas o seu título: o autor, a categoria, o resumo. Guardar toda esta informação num array indexado obrigaria a memorizar que o índice 0 corresponde sempre ao título, o 1 ao autor, e assim sucessivamente, um código difícil de ler e fácil de errar. Um array associativo resolve exatamente este problema: cada valor é acedido através de uma chave à escolha, tipicamente uma string, em vez de um índice numérico, o que torna o código muito mais legível quando cada valor tem um significado próprio:

<?php
$artigo = array(
    "titulo"    => "Entrevista: o futuro do jornalismo local",
    "autor"     => "Rita Ferreira",
    "categoria" => "Tecnologia"
);

echo $artigo["titulo"];   // Entrevista: o futuro do jornalismo local
echo $artigo["autor"];    // Rita Ferreira

// acrescenta uma nova chave
$artigo["resumo"] = "Uma conversa sobre os desafios do jornalismo de proximidade.";

Um artigo da Contraponto deixa, assim, de ser apenas um texto solto dentro do array $titulos, e passa a ser, ele próprio, um array associativo com todas as suas propriedades. Esta ideia, um array associativo dentro de outro array, é precisamente o tema da secção seguinte.

3.8.3 Arrays Multidimensionais

Um array multidimensional é um array cujos valores são, eles próprios, outros arrays, o que permite representar dados mais estruturados, como categorias com listas de itens, ou uma lista de registos, cada um com vários campos, exatamente o problema levantado no final da secção anterior:

<?php
$revistas_concorrentes = array(
    "generalistas" => array("Visão", "Sábado", "Expresso"),
    "culturais"    => array("Ler", "Blimunda", "Time Out")
);

echo $revistas_concorrentes["generalistas"][0];  // Visão
echo $revistas_concorrentes["culturais"][1];     // Blimunda

// Um array de registos, cada um por sua vez um array associativo:
// exatamente o esboço de "Artigo" proposto por Tiago no @sec-03-projeto
$artigos = array(
    array(
        "titulo"    => "Entrevista: o futuro do jornalismo local",
        "autor"     => "Rita Ferreira",
        "categoria" => "Tecnologia"
    ),
    array(
        "titulo"    => "Crítica: a nova exposição do museu",
        "autor"     => "Marco Antunes",
        "categoria" => "Cultura"
    ),
    array(
        "titulo"    => "Como nasceu a Contraponto",
        "autor"     => "Rita Ferreira",
        "categoria" => "Cultura"
    )
);

echo $artigos[0]["titulo"];  // Entrevista: o futuro do jornalismo local
echo $artigos[2]["autor"];   // Rita Ferreira

O array $artigos é a estrutura que finalmente dá corpo ao modelo proposto no Secção 3.2: cada elemento é um artigo completo, com toda a sua informação, e a lista inteira continua a poder ser percorrida, contada e ordenada com as mesmas funções vistas na Secção 3.8.1. É também com este mesmo array, em memória, que Tiago vai construir as primeiras páginas do sítio, muito antes de ligar a aplicação a uma base de dados real; este último exemplo, um array de arrays associativos, é de resto a forma mais comum de representar, em memória, um conjunto de registos vindos de uma base de dados, tema retomado com mais detalhe no Secção 8.1.

Para inspecionar rapidamente o conteúdo de um array durante o desenvolvimento, sem ter de aceder a cada elemento individualmente, usa-se a função print_r(), que mostra a sua estrutura completa, incluindo arrays aninhados, ou var_dump(), que mostra ainda o tipo e o comprimento de cada valor.

3.8.4 Exemplo Completo: Vistas de um Autor

Um pequeno exemplo, juntando variáveis, tipos, conversão e arrays multidimensionais, mostra bem como estes conceitos se combinam na prática: calcular a média de vistas dos últimos artigos de um autor, guardadas dentro de um array associativo com os seus dados:

<?php
$autor = [
    "nome"   => "Rita Ferreira",
    "vistas" => [1200, 850, 430, 610]
];

1$soma = array_sum($autor["vistas"]);
2$numero_artigos = count($autor["vistas"]);
3$media = $soma / $numero_artigos;

echo $autor["nome"] . " tem uma média de " . $media . " vistas por artigo";

4if ($media >= 500) {
    echo ", um alcance acima da média da revista.";
} else {
    echo ", um alcance abaixo da média da revista.";
}
1
Soma as vistas dos últimos artigos: 1200 + 850 + 430 + 610 = 3090.
2
Conta quantos artigos foram somados: 4.
3
Divide a soma pelo número de artigos, obtendo a média: 3090 / 4 = 772,5.
4
Compara a média com o valor de referência da revista, decidindo o resultado final.

Note-se que array_sum() devolve um float sempre que a divisão não é exata, mesmo que todas as vistas somadas sejam inteiras, o que é consistente com o comportamento de tipagem dinâmica visto na Secção 3.7: o PHP escolhe automaticamente o tipo mais adequado ao resultado de cada operação.

O código completo da demonstração feita na aula sobre variáveis e arrays, pronto a copiar, está disponível no Secção B.2.

3.9 Desafio

Tiago já sabe representar um artigo, e uma lista de artigos, em arrays. Antes de avançar para o próximo capítulo, o desafio é pôr esse conhecimento à prova, completando o catálogo de artigos da Contraponto, usando apenas o que já foi visto neste capítulo, sem ciclos nem condicionais:

  1. Completar o array $artigos com pelo menos cinco artigos, cada um com título, autor e categoria;
  2. Mostrar o título do terceiro artigo do catálogo;
  3. Construir um array $categorias com as categorias já usadas nos artigos, sem repetições, e ordená-lo por ordem alfabética com sort();
  4. Verificar, com in_array(), se a categoria "Entrevistas" já está representada no catálogo.

O ficheiro de arranque, com o array $artigos parcialmente preenchido, está disponível no Secção C.2.
