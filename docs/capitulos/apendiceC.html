C.1 Introdução

No final de cada capítulo, uma secção “Desafio” propõe um pequeno exercício que aplica, ao projeto da Revista Contraponto apresentado no Secção 3.2, apenas as ferramentas da linguagem já vistas até esse ponto do livro. Este apêndice reúne o ficheiro de arranque de cada um desses desafios, com parte do código já escrito e o resto assinalado com comentários TODO, para que o trabalho de cada aluno seja completar e estender o que já está feito, em vez de começar sempre do zero.

C.5 Desafio do Capítulo 7: Pedidos Reais com GET e POST

Ficheiro de arranque para o desafio do Secção 7.9. O header.php e o footer.php mantêm-se iguais aos do capítulo anterior; o index.php já tem a função formatarArtigo() completa, tal como resolvida no Secção 5.4, faltando apenas substituir a variável fixa pelo valor real de $_GET["categoria"], e tratar a submissão do formulário de comentário.

<!-- header.php -->
<header>
    <h1>Contraponto</h1>
    <nav>
        <a href="index.php">Início</a> |
        <a href="index.php?categoria=Cultura">Cultura</a> |
        <a href="index.php?categoria=Tecnologia">Tecnologia</a> |
        <a href="index.php?categoria=Música">Música</a>
    </nav>
</header>
<!-- footer.php -->
<footer>
    <p>&copy; 2026 Revista Contraponto. Todos os direitos reservados.</p>
</footer>
<!-- index.php -->
<?php
// Desafio do Capítulo 7: pedidos reais com $_GET e $_POST
//
// 1. Substituir a linha de $categoria_escolhida pelo valor real de
//    $_GET["categoria"], com isset() a tratar o caso de não existir
//    (nesse caso, mostrar todos os artigos);
// 2. Tratar a submissão do formulário de comentário: verificar se
//    $_SERVER["REQUEST_METHOD"] é "POST" e, nesse caso, mostrar uma
//    mensagem de confirmação com $_POST["nome"] e $_POST["texto"].

function formatarArtigo($artigo) {
    return $artigo["titulo"] . " — por " . $artigo["autor"];
}

$artigos = array(
    array(
        "titulo"    => "Entrevista: o futuro do jornalismo local",
        "autor"     => "Rita Ferreira",
        "categoria" => "Tecnologia"
    ),
    array(
        "titulo"    => "Crítica: a nova exposição do museu",
        "autor"     => "Marco Antunes",
        "categoria" => "Cultura"
    ),
    array(
        "titulo"    => "Como nasceu a Contraponto",
        "autor"     => "Rita Ferreira",
        "categoria" => "Cultura"
    ),
    array(
        "titulo"    => "Roteiro cultural de outubro",
        "autor"     => "Marco Antunes",
        "categoria" => "Música"
    ),
    array(
        "titulo"    => "Como a IA está a mudar o jornalismo",
        "autor"     => "Rita Ferreira",
        "categoria" => "Tecnologia"
    )
);

// TODO 1: substituir esta linha pela leitura de $_GET["categoria"]
$categoria_escolhida = "Tecnologia";

require "header.php";

foreach ($artigos as $artigo) {
    if ($artigo["categoria"] === $categoria_escolhida) {
        echo "<p>" . formatarArtigo($artigo) . "</p>";
    }
}

// TODO 2: tratar a submissão do formulário de comentário, por POST

require "footer.php";
