4.1 Estruturas Condicionais

Com o catálogo de artigos completo, Tiago repara que nem tudo o que está no array $artigos deve ser tratado da mesma forma: um artigo pode estar pronto a publicar, ou pode ainda ser apenas um rascunho que Rita está a rever. Com o que sabe até aqui, o único código que consegue escrever é um echo direto, sempre executado da mesma maneira, sem nunca variar consoante os dados: não há forma de dizer “mostra isto se o artigo estiver publicado, mas não se ainda for rascunho”. É exatamente este tipo de decisão que uma estrutura condicional permite tomar: avalia se uma condição é verdadeira ou falsa, e executa um bloco de código diferente consoante o resultado, direcionando o fluxo do programa de acordo com os dados. Em PHP, a estrutura mais comum é o if/else, e resolve bem o problema do estado do artigo:

<?php
$estado = "publicado";

if ($estado === "publicado") {
    echo "Mostrar o artigo aos leitores.";
} else {
    echo "Artigo ainda em rascunho, não mostrar.";
}

Isto resolve bem uma decisão de sim ou não. Mas Tiago tem outro problema parecido: quer que a página inicial destaque os artigos consoante o número de vistas que já tiveram, e desta vez há mais do que duas categorias possíveis, não apenas “viral” ou “não viral”. Um único if/else só distingue dois casos; quando há mais do que duas alternativas, encadeia-se elseif:

<?php
$vistas = 850;

if ($vistas >= 1000) {
    echo "Viral";
} elseif ($vistas >= 500) {
    echo "Popular";
} elseif ($vistas >= 100) {
    echo "Normal";
} else {
    echo "Pouco lido";
}

Este problema das vistas resolve-se bem com elseif porque cada alternativa depende de uma faixa diferente de valores. Mas quando Tiago quer decidir a secção do sítio a partir da categoria exata de um artigo, comparando sempre a mesma variável $categoria com vários valores possíveis, um a um, escrever um elseif para cada categoria começa a ficar repetitivo: elseif ($categoria === "Cultura"), elseif ($categoria === "Música"), e assim sucessivamente. Há uma outra maneira mais simples de Tiago fazer a mesma coisa, sempre que o que está em causa é comparar uma única variável com vários valores exatos: o switch. Repare-se no uso do break: sem ele, a execução continuaria para o case seguinte mesmo depois de encontrar uma correspondência, um comportamento chamado fallthrough, por vezes usado propositadamente, como nas duas primeiras linhas do exemplo, para agrupar vários casos sob a mesma secção do sítio:

<?php
$categoria = "Música";

switch ($categoria) {
    case "Cultura":
    case "Música":
        echo "Secção Lazer";
        break;
    case "Tecnologia":
        echo "Secção Inovação";
        break;
    default:
        echo "Outras notícias";
}

4.1.1 Operadores de Comparação

Ao testar o if do estado do artigo, Tiago tropeça num pormenor do PHP que vale a pena perceber bem antes de continuar. As condições assentam em operadores de comparação, que avaliam dois valores e devolvem sempre um booleano, true ou false:

Operador Significado
== igual (compara apenas o valor)
=== idêntico (compara o valor e o tipo)
!= diferente (compara apenas o valor)
!== não idêntico (compara o valor e o tipo)
< menor que
> maior que
<= menor ou igual a
>= maior ou igual a

A distinção entre == e === é uma das fontes mais comuns de erros subtis em PHP, precisamente por o PHP converter automaticamente entre tipos ao usar ==:

<?php
var_dump(0 == "abc");    // false na maioria das versões atuais do PHP
var_dump(0 == "0");      // true: "0" é convertido para o número 0
var_dump(0 === "0");     // false: tipos diferentes, integer vs string
var_dump("10" == "1e1"); // true: ambos convertidos para o mesmo número
var_dump("10" === "1e1");// false: são strings diferentes

Por esta razão, é boa prática usar === sempre que se quer garantir que dois valores são realmente iguais, tanto no valor como no tipo, evitando comparações que dependam de conversões automáticas nem sempre óbvias. Esta distinção vai ser particularmente relevante mais adiante no livro, quando Tiago começar a receber dados de pedidos HTTP reais, na Secção 7.5: um identificador de artigo recebido pela URL chega sempre como string, mesmo que represente um número, e comparar essa string com um id guardado como integer pode ter resultados inesperados se se usar == em vez de ===.

4.1.2 Operadores Lógicos

Tiago percebe que mostrar um artigo, na prática, depende de duas condições ao mesmo tempo: o artigo tem de estar publicado, e a sua categoria não pode entretanto ter sido arquivada. Testar isto com dois if separados obrigaria a aninhar um dentro do outro; combinar as duas condições numa só é o papel dos operadores lógicos:

  • and (ou &&): verdadeiro apenas se ambas as condições forem verdadeiras;
  • or (ou ||): verdadeiro se pelo menos uma das condições for verdadeira;
  • xor: verdadeiro se exatamente uma das duas condições for verdadeira, mas não ambas.
<?php
$publicado = true;
$categoria_ativa = true;

if ($publicado && $categoria_ativa) {
    echo "Mostrar artigo.";
}

4.2 Ciclos

Um ciclo (ou loop) é uma estrutura de controlo que permite repetir a execução de um bloco de código várias vezes, até que uma condição especificada deixe de se verificar, ou até que um número predeterminado de repetições seja alcançado. O PHP disponibiliza quatro tipos de ciclos.

4.2.1 for

Usa-se quando se sabe, à partida, quantas repetições são necessárias, recebendo três parâmetros: o valor inicial, a condição de paragem, e o incremento aplicado a cada repetição:

<?php
for ($pagina = 1; $pagina <= 5; $pagina++) {
    echo "Página $pagina ";
}
// Página 1 Página 2 Página 3 Página 4 Página 5

4.2.2 while

Recebe apenas uma condição, avaliada antes de cada repetição; se a condição for falsa logo à partida, o bloco de código nunca chega a executar. No painel de gestão da Contraponto, um editor pode usar um while para ir despachando, um a um, os comentários ainda por aprovar:

<?php
$comentarios_pendentes = 5;
while ($comentarios_pendentes > 0) {
    echo "Comentário pendente: $comentarios_pendentes ";
    $comentarios_pendentes--;
}

4.2.3 do...while

Muito semelhante ao while, mas com a condição avaliada depois de cada repetição, o que garante que o bloco de código executa sempre pelo menos uma vez, mesmo que a condição seja falsa logo à partida. É útil, por exemplo, para garantir que a página inicial mostra sempre algum artigo em destaque, mesmo nos dias em que nenhum foi explicitamente marcado como tal:

<?php
$artigos_destaque = 0;   // nenhum artigo marcado como destaque hoje
do {
    echo "A mostrar o artigo mais recente como destaque. ";
    $artigos_destaque--;
} while ($artigos_destaque > 0);
// executa uma vez, mesmo com a condição já falsa à partida

4.2.4 foreach

Usado especificamente para percorrer arrays, sem necessidade de gerir um índice manualmente. É finalmente com um foreach que Tiago consegue transformar o array $titulos, esboçado na Secção 3.8.1, numa lista real de artigos na página do sítio, sem repetir echo uma vez por artigo:

<?php
$titulos = [
    "Entrevista: o futuro do jornalismo local",
    "Crítica: a nova exposição do museu",
    "Como nasceu a Contraponto"
];

foreach ($titulos as $titulo) {
    echo $titulo . "<br>";
}

Com um array associativo, o foreach permite aceder simultaneamente à chave e ao valor de cada elemento, o que serve, por exemplo, para mostrar todos os campos de um único artigo sem escrever echo para cada propriedade em separado:

<?php
$artigo = [
    "titulo"    => "Entrevista: o futuro do jornalismo local",
    "autor"     => "Rita Ferreira",
    "categoria" => "Tecnologia"
];

foreach ($artigo as $chave => $valor) {
    echo "$chave: $valor<br>";
}

4.3 Desafio

Com condicionais e ciclos, Tiago já consegue transformar o catálogo estático de artigos numa página que reage aos dados. O desafio, a partir do catálogo $artigos completado na Secção 3.9, é:

  1. Usar um foreach para percorrer $artigos e mostrar o título de cada um;
  2. Dentro do mesmo foreach, usar um if para mostrar também o autor, mas apenas dos artigos cuja categoria seja "Cultura";
  3. Definir, no topo do ficheiro, uma variável $categoria_escolhida = "Tecnologia";, a simular, por agora, a categoria que o leitor quer ver, e usar um if para que o foreach só mostre os artigos dessa categoria.

O ficheiro de arranque, já com o catálogo completo do capítulo anterior, está disponível na Secção C.3. Esta variável fixa é, propositadamente, uma simplificação: a Secção 7.5 mostra como substituí-la pelo valor real de um pedido do browser, através de $_GET.
