C.1 Introduction

At the end of each chapter, a “Challenge” section proposes a small exercise that applies, to the Contraponto Magazine project presented in Section 3.2, only the language tools already covered up to that point in the book. This appendix gathers the starter file for each of these challenges, with part of the code already written and the rest marked with TODO comments, so that each student’s job is to complete and extend what is already there, instead of always starting from scratch.
